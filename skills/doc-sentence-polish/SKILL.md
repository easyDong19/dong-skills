# doc-sentence-polish

## Overview

기술 문서의 문장을 효과적이고 간결하게 다듬는다. 핵심 원칙: **의미(내용)는 바꾸지 않고 표현만 개선한다.**

## When to Use

- 문장이 길고 장황해서 핵심이 안 보일 때
- 수동태·번역투·모호한 표현이 섞여 있을 때
- 용어가 문서 안에서 오락가락할 때
- 영어를 직역한 비유·조어가 실무 용어 대신 쓰였을 때

**When NOT to use**
- 목차·페이지 구조 수준의 피드백 → `doc-structure-review` 스킬
- AI 문체 제거·휴머나이징 → `humanize-korean` 스킬

## 6개 원칙

1. **필요한 정보만 남기기** — 짧고 간결하게, 한 문장에 하나의 생각만.
   체크: 불필요하게 길거나 복잡한가? 한 문장에 여러 아이디어가 혼재하는가?
2. **메타 담화 최소화** — 핵심 전달을 방해하는 '말에 대한 말'을 제거한다.
   체크: "앞서 설명했듯이", "여러분도 아실 것입니다" 같은 불필요한 서술이 없는가?
3. **구체적으로 쓰기** — 모호한 표현 대신 구체적·직접적 언어를 쓴다.
   체크: 불명확한 표현·추상적 용어가 없는가? 동사로 명확한 행동 지시를 하는가?
4. **일관되게 쓰기** — 용어·표현을 문서 전체에서 통일한다.
   체크: 같은 개념이 여러 표현으로 흩어지지 않는가? 약어·외래어는 처음 등장 시 풀어서 표기하는가?
5. **문장의 주체를 분명하게** — 주어가 명확해야 독자가 행동을 파악한다.
   체크: 수동형을 능동형으로 바꿀 수 있는가? 도구·기술이 아니라 독자(개발자)가 주체인가?
6. **직역 용어 대신 실무 용어 쓰기** — 영어 표현을 우리말로 옮기며 만든 비유·조어를 한국 개발 현장에서
   실제로 쓰는 말로 바꾼다. 독자가 한 번 더 번역해야 하는 말은 쓰지 않는다.
   체크: 업계에 이미 통용되는 용어(롤백, 배포 브랜치, fast-forward, 빌드 산출물)가 있는데 새로 만든
   우리말(되돌리기, 표지판, 앞으로만 옮기기, 결과물)을 쓰지 않았는가? 영어 동사를 그대로 옮긴 어색한
   서술(박힌다, 내보낸다, 가른다)이 없는가? 문서 형식을 가리키는 말(box → "상자")을 본문에 옮기지 않았는가?
   실무 용어가 비개발자에게 낯설 수 있으면 우리말로 바꾸지 말고 용어표나 첫 등장 괄호에 뜻을 단다.

### 직역 용어 → 실무 용어 예시

| 직역·조어 | 실무 용어 |
| --- | --- |
| 되돌리기 | 롤백 |
| 표지판, 이름표 (branch/pointer 비유) | 배포 브랜치, 브랜치 |
| 앞으로만 옮긴다 | fast-forward로만 이동한다 |
| 결과물, 빌드 결과물 | 빌드 산출물 |
| (설정값이) 박힌다 | (빌드할 때) 포함된다, 결정된다 |
| 내보낸다 (serve) | 서비스한다, 내려준다 |
| 초록불 (green check) | 워크플로 성공 표시 |
| 가른다, 가르기 (triage) | 판단한다, 원인을 좁힌다, 원인 찾기 |
| 갈래 | 경로 |
| 허락하는 곳 | 처리하는 곳 |
| 목적지 | 배포 대상 |
| 한 끝 차이 | 이름이 비슷하다 (`-v2` 하나 차이) |
| 상자 (callout box) | 이 절, 이 항목 |
| 미리보기로 받아 둔다 | preview 배포로 처리한다 |

## 출력 형식

1. **원칙별 문제 피드백** — 6개 원칙 중 걸리는 항목만 짚는다.
2. **최종 수정안 하나** — 여러 개선 옵션을 모두 통합한 단일 수정안을 제시한다. 옵션을 나열하지 않는다.
3. **한 줄 요약** — 무엇을 왜 바꿨는지.

제약: 의미(내용)는 바꾸지 않는다. 표현만 개선한다.

## Common Mistakes

- 수정안을 여러 개 나열한다 → 통합된 **하나**만 제시한다.
- 다듬으면서 내용을 추가·삭제한다 → 표현만 바꾼다.
- 문제 없는 원칙까지 억지로 지적한다 → 걸리는 항목만 짚는다.
- 전체 문서 구조를 재편하려 든다 → 문장 수준에 머문다.
- 비개발자 독자를 배려한다며 실무 용어를 직역 조어로 바꾼다 → 실무 용어는 유지하고 뜻을 덧붙인다.
