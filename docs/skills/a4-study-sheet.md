# a4-study-sheet

공부한 내용을 **시험·면접 직전에 손에 들고 볼 흑백 A4 한 장**으로 줄인다. 결과는 인쇄용 HTML이고, 브라우저에서 바로 인쇄하면 된다.

> 플러그인: `dong-study` · 의존성: [diagram-design](https://github.com/cathrynlavery/diagram-design) (그림을 그릴 때 원칙을 불러 쓴다). 설치는 [README](../../README.md#설치).

## 언제 쓰나

- **면접 직전 5분.** 한 주 동안 공부한 주제를 한 장에 모아, 대기실에서 훑어볼 때.
- **흑백 프린터로 뽑을 치트시트.** 색으로 구분하지 않고 굵기 · 테두리 · 점선으로 구분하므로 흑백으로 뽑아도 읽힌다.
- **긴 학습 자료의 마지막 정리.** [study-explainer](study-explainer.md)로 만든 긴 설명 페이지를 한 장으로 압축할 때.

## 이렇게 부른다

```
오늘 공부한 이벤트 루프 내용 A4 한 장으로 정리해줘
```
```
면접 전에 볼 거라 흑백으로 인쇄할 커닝페이퍼 만들어줘
```

## 결과 예시

"비동기 & 이벤트 루프" 주제를 한 장으로 만든 결과다. 맨 위 한 줄 정의 박스, 번호 붙은 섹션 4개, 마지막 "반사 카드"(0.5초 안에 답할 문장)와 점선 "헷갈리지 말 것" 박스로 끝난다.

![A4 한 장 요약 예시](../images/a4-study-sheet/sheet.png)

같은 주제의 긴 설명 페이지는 [study-explainer 결과 예시](study-explainer.md#결과-예시)에 있다. 긴 버전으로 이해하고, 이 한 장으로 복습하는 짝이다.

## 그림 넣기 (diagram-design과 함께)

배열이 바뀌는 단계, 경계선, 재귀 트리처럼 **표로 쓰면 다섯 줄인데 그림이면 한눈인 것**은 인라인 SVG로 그린다. 판단 기준은 diagram-design에서, 생김새는 이 스킬의 흑백 규칙에서 가져온다.

| diagram-design에서 가져오는 것 | 이 스킬이 정하는 것 |
| --- | --- |
| 덜어내기 (배치로 보이는 관계는 선을 지운다) | 색 없이 검정 · 회색만, 강조는 굵은 선과 굵은 글자 |
| 밀도 4/10, 요소 9개를 넘으면 둘로 나눈다 | 실선 = 있는 것, 점선 = 사라질 것 |
| 강조는 한두 곳 | 라벨은 본문 글꼴, 값은 monospace |
| `<title>` · `<desc>` 접근성 | A4 HTML 안에 `<svg>`를 직접 쓴다 (독립 파일 아님) |

그림을 넣으면 **그림이 대신한 표 · 문장은 지운다.** 아래는 정렬 · 이분 탐색 시트의 1쪽이다. 오른쪽 위 "unique 후 · erase 후" 배열 그림과 가운데 "lower_bound / upper_bound 경계선" 그림이 각각 표 몇 줄을 대신한다.

![그림이 들어간 A4 요약](../images/a4-study-sheet/sheet-figures.png)

diagram-design이 설치돼 있지 않으면 스킬 본문의 요약 원칙만으로 그린다.

## 저장 위치

1. 사용자가 위치를 지정하면 거기에 쓴다.
2. 학습 정리 저장소에서 작업 중이면 그 주제 폴더의 `A4정리/`에 모은다.
3. 그 외에는 현재 작업 폴더의 `A4정리/<주제>_핵심정리.html`.

같은 폴더에 이미 만든 시트가 있으면 새로 디자인하지 않고 그 CSS를 가져와 톤을 맞춘다.
